Satisfactory Analyzer

A Satisfactory save is a few thousand compressed objects, and the game never adds them up for you. Drop one in and you get the total: where you are in the tech tree, every building and what it is making, the belts, the power, what is in every box. Drop in a folder of saves and you get the order it all happened in.

One save, read in full.

Saves live in %LOCALAPPDATA%\FactoryGame\Saved\SaveGames\<id> on Windows and in saved/server on a dedicated server. Opening one is read-only, so pointing this at a live save is safe.
